1總覽：基座模型 → 助理

SFT 用「指令—答案」配對，把只會預測下一個詞的基座模型，變成會聽指令、具備領域知識的助理。

好樣本的三個特性

正確（答案無誤且對應指令） · 多樣（涵蓋主題、長度、文體） · 困難（含多步驟推理）。 核心規則：品質重於數量。

名詞速查

名詞白話解釋
指令（Instruction）給模型的輸入
答案（Output）模型應輸出的回覆
系統提示（System）全域行為規則
對話模板system / user / assistant 的固定格式
Alpaca 格式欄位：instruction、input（可省略）、output
ShareGPT / OpenAI 格式訊息清單，可做多輪對話

樣本數量指引

情境建議數量
通用助理約 1,000,000 筆
單一任務（翻譯、摘要）100–100,000 筆
大模型（約 70B）1,000 筆高品質樣本即可見效
小模型（約 7B）需更多樣本學對話格式

3模板實驗室：一格空格錯誤即失敗

訓練樣本會被格式化成模板字串。左邊改文字，右邊即時看渲染結果。開「顯示空白字元」檢查每個空格。


      
書中訓練用的是 Alpaca 模板 + tokenizer.eos_token（Llama 3.1 基座為 <|end_of_text|>）。推理時用一模一樣的模板；差一個空格，模型行為就會異常或不停。

  全量 ≈ 16 bytes/參數（fp32 權重 4＋梯度 4＋Adam 狀態 8）。LoRA ≈ bf16 凍結權重 2＋r=32 適配器開銷。QLoRA ≈ 4-bit 權重 0.5＋適配器開銷。7B 全量 7×16=112 GB，與書中表格一致。
